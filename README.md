
# AI-Assisted Azure Technology Risk & Controls Assessment

## Project Overview

This project demonstrates a First Line of Defence
technology risk assessment for a fictional 
insurance company migrating a customer-facing
application to Microsoft Azure.

## Objectives

- Identify and assess Azure technology risks
- Evaluate security control effectiveness
- Test controls using actual Azure lab evidence
- Apply AI to assist with evidence analysis
- Document findings and remediation recommendations
- Produce management-level technology risk reporting

## Frameworks

- NIST Cybersecurity Framework 2.0
- ISO/IEC 27001:2022
- OSFI Guideline B-13

## Technologies

Microsoft Azure, Python, GitHub, and AI-assisted
evidence analysis tools.

## Disclaimer

This is an independent portfolio project.
All business scenarios and customer data are synthetic.
